# Blok 7 – osobné portfólio

## Súbory
- `index.html` – obsah stránky
- `styles.css` – vzhľad a responzivita
- `script.js` – mobilné menu a jemné animácie
- `favicon.svg` – ikona stránky
- `img/` – sem vlož vlastné fotografie

## Čo treba pred odovzdaním doplniť
1. Nahraď `[TVOJE MENO]` svojím menom.
2. Nahraď `[TVOJ-EMAIL]` a `[DOPLŇ SVOJ E-MAIL]` funkčným e-mailom.
3. Vlož vlastnú fotografiu do `img/fotka.jpg`.
4. Skontroluj, či tri uvedené projekty zodpovedajú tomu, čo si skutočne vytvoril. Doplň výsledky a odkazy, ak ich máš.
5. Ak máš `docs/style-guide.md` z predchádzajúceho bloku, uprav CSS premenné v hornej časti `styles.css` podľa jeho farieb, písma a nálady.
6. Pridaj stiahnutý obrázok Unsplash ako `img/hero.jpg` a podľa potreby požiadaj Copilot, aby ho použil ako pozadie hero sekcie.

## Spustenie
Otvor priečinok vo Visual Studio Code a otvor `index.html` cez Live Preview.

## Kontrola
- Skontroluj všetky odkazy a sekcie.
- Vyskúšaj mobilné menu.
- Stlač F12 a otestuj šírku 375 px a 768 px.
- Po každej úprave obnov Live Preview.
- Po dokončení ulož zmeny cez Git commit.

Poznámka: Farebná paleta v tejto verzii je dočasná, pretože súbor `docs/style-guide.md` nebol v dostupných súboroch nájdený.
